# Morse Code

## Overview
Morse code is a communication system that represents letters, numbers, and punctuation using sequences of short and long signals, known as **dots (·)** and **dashes (–)**. It was originally designed for telegraphy but has also been used with radio signals, flashing lights, and audible tones.

## Historical Context
Morse code was developed in the 1830s and 1840s by **Samuel Morse** and **Alfred Vail**. It was created to allow messages to be sent quickly over long distances using telegraph lines.  
During the late 19th and early 20th centuries, Morse code became essential for maritime communication, military operations, and aviation. The famous distress signal **SOS (· · · – – – · · ·)** was adopted internationally in 1905.

## How the System Works
- Each character is represented by a unique combination of dots and dashes.  
- A **dot** is a short signal (one unit).  
- A **dash** is a longer signal (three units).  
- Spacing rules:  
  - Between parts of the same letter → 1 unit  
  - Between letters → 3 units  
  - Between words → 7 units  

### Examples
- **A** → · –  
- **B** → – · · ·  
- **C** → – · – ·  
- **HELLO** → ···· · ·–·· ·–·· –––  
- **WORLD** → ·––– ––– ·–· ·–·· –··  
- **SOS** → · · · – – – · · ·  

Morse code can be transmitted by sound (beeps), light (flashes), or electrical pulses. Timing and spacing are critical to ensure clarity.
